# 蜗轮蜗杆校核指南（新手版）

这份指南把本模块分成两层：**必做的几何与基础性能计算**，以及**可选的 Load Capacity 负载能力预校核**。先用案例跑通，再替换自己的项目数据。

本文依据当前代码、模块帮助和公开工程资料整理，**未查证原始标准正文（Cannot verify against original DIN standard）**，不引用或代述标准的具体条款。

## 1. 先判断是否适用

**适用：**

- 常规圆柱蜗杆副的 DIN 3975 风格几何与基础性能估算。
- 已知模数、头数/齿数、直径系数、中心距、转速、输入扭矩和材料组合的方案比较。
- 启用 Load Capacity 后，对齿面接触与齿根弯曲安全系数做 **DIN 3996 Method B 风格最小子集**预校核。

**不适用：**

- 需要完整 DIN 3996 / ISO/TS 14521 合规结论或正式签发的场合。
- 需要完整接触线积分、油膜/瞬时温度、胶合、公差与接触斑点、载荷谱累积损伤等专项分析的场合。
- 希望使用 Method C 的场合：**当前版本明确拒绝 Method C**，选择后执行计算会提示需要 FEA 输入、尚未实现。

只做几何时，结果不包含齿面和齿根强度结论；启用 Load Capacity 才会计算这些安全系数。

## 2. 用测试案例 1 最快上手

1. 点击顶部 **测试案例 1**，载入一组钢蜗杆 + PA66+GF30 蜗轮、已启用负载能力的输入。
2. 点击 **执行校核**。
3. 先看几何总览：传动比 `i`、中心距 `a`、计算导程角和主要尺寸。
4. 再看基础性能：输出扭矩、效率、功率损失、自锁提示和性能曲线。
5. 打开 **Load Capacity** 与结果页，查看齿面/齿根应力、安全系数 `SH` / `SF`、目标门槛和警告。
6. 回到“基本设置”，把负载能力改为“不启用”再计算一次，观察结果如何只保留几何与基础性能。

案例 1 只用于熟悉流程，不是材料许用值或安全系数的通用推荐。

## 3. 输入前准备什么

- **几何**：模数 `m`、蜗杆头数 `z1`、蜗轮齿数 `z2`、直径系数 `q`、中心距、齿宽、变位系数和图纸导程角。
- **工况**：输入扭矩、输入转速、工况系数 `KA` 和扭矩波动。连续/间歇、换向频次与完整载荷谱目前没有独立输入，必须在模块外另行评估。
- **材料与环境**：蜗杆/蜗轮材料、弹性模量、泊松比、润滑方式、工作温度和湿度。
- **负载能力附加数据**：有依据的许用齿面/齿根应力、`Kv`、`KHalpha`、`KHbeta`，以及目标安全系数 `SH_min`、`SF_min`。

当前材料选择器只覆盖 `37CrS4` 蜗杆与五种塑料蜗轮。钢-青铜等其他材料副不能在当前页面中选择，不要通过改名或照搬塑料案例值来模拟；应改用支持该材料副的计算链路，并从材料供应商、企业规范或经核实的标准资料取得输入。

## 4. 推荐计算顺序

1. **基本设置**：初次使用选择 Method B；决定是否启用 Load Capacity。不要选择 Method C 试图得到近似结果，它会被拒绝。
2. **几何**：依次填写 `m`、`z1`、`z2`、`q`、变位和齿宽，核对中心距与导程角是否自洽。
3. **材料与工况**：选择材料/润滑，填写扭矩、转速、`KA`、温湿度和其他实际工况。
4. **高级参数**：核对压力角等模型输入，不确定时不要无依据修改默认值。
5. **Load Capacity（可选）**：确认许用应力与 `Kv`、`KHalpha`、`KHbeta` 的来源，再设置目标安全系数。
6. 点击 **执行校核**，按“几何一致性 → 基础性能 → 负载能力 → 警告与模型说明”的顺序读结果。

## 5. 怎样读结果

- **几何与基础性能结果**：无论是否启用 Load Capacity 都会给出。重点核对传动比、中心距、导程角、主要直径、输出扭矩、效率、损失和自锁提示是否符合方案预期。
- **几何警告**：表示输入之间可能不自洽或接近模型边界；不能因为后续某个安全系数通过就忽略。
- **齿面安全系数 `SH`**：许用齿面应力与计算接触应力之比，应达到设定的 `SH_min`。
- **齿根安全系数 `SF`**：许用齿根应力与计算弯曲应力之比，应达到设定的 `SF_min`。
- **总体结果**：只汇总当前已执行的判据。负载能力未启用时，不应把“未校核”理解为“强度通过”。
- **寿命/磨损结果**：是单一稳态工况下的简化估算，适合比较方案，不等同于完整载荷谱寿命验证。

## 6. 不通过时优先怎么调

- 几何不自洽：先核对 `m`、`q`、`z1/z2`、中心距、变位与图纸导程角；这些量彼此约束，不要逐项独立“凑数”。
- 齿面 `SH` 不足：优先复核实际扭矩与载荷系数，在结构允许时增大模数/中心距或有效齿宽，并评估更合适的材料和润滑方案。
- 齿根 `SF` 不足：可评估增大模数、齿宽、齿根有效厚度或材料强度，并降低真实峰值载荷。
- 效率低或发热高：检查导程角、材料副、润滑、转速与载荷是否适配；不要把自锁要求与高效率目标混为一谈。
- `KHbeta` 偏大：优先改善支承刚度、对中和齿宽载荷分布；没有装配证据时，不要简单把它调回 1.0。

每次调整一个主要变量，重新检查几何、性能和强度三层结果，避免修好一项却恶化另一项。

## 7. 模型边界与下一步

当前负载能力路径是 **Method B 风格最小子集**：齿面使用线接触 Hertz 近似，齿根使用等效悬臂梁近似，并用 `KA * Kv * KHalpha * KHbeta` 修正载荷；它没有实现完整 Method B 的全部标准系数链。Method C 未实现并会被明确拒绝。

因此，本模块适合方案估算和初筛。高功率、连续重载、高温、关键安全件、塑料长期寿命、胶合/磨损敏感或需要标准合规签发的设计，应继续做完整标准校核、热与润滑分析、接触分析/FEA，并结合材料数据和试验验证。
