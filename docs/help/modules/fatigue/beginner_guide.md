# 疲劳强度与可靠性预校核指南

## 先判断是否适用

本模块适用于金属、刚性/半刚性工程塑料和短纤增强塑料的单轴有限寿命预校核。需要准备恒幅 S-N/Wöhler 试验数据，以及零件热点位置的应力块谱或单通道载荷时序。

连续纤维层合板（属于 ISO 13003 等独立试验体系）、多轴/非比例载荷、低周应变寿命、裂纹扩展、腐蚀或蠕变疲劳不在首版范围。

## 最快上手

1. 点击“测试案例 1”，加载三应力级、15 件断裂和 1 件 runout，以及两级应力块谱。
2. 为快速试跑可把 bootstrap 次数暂改为 `0`；正式默认值是 Monte Carlo `20000`、bootstrap `500`、种子 `1729`。
3. 点击“执行预校核”。
4. 先看数据充分性、条件一致性和实测范围，再看 Miner 损伤和可靠度。前三项不完整时，模块不会给出通过。

## 正式数据流程

- S-N 数据可使用应力幅/平均应力，或最大/最小应力；状态必须明确为断裂或 runout。
- 块谱使用幅值、均值和循环数；时序使用时间和值，经转折点提取与 rainflow 转成循环。
- 如果谱是力或扭矩，必须给线性传递系数或覆盖全输入范围的单调载荷-应力查表。
- 塑料必须记录温湿度、频率、R 比、成型/取样方向和调湿状态；条件不一致的数据不要合并。

## 结果口径

主拟合是包含 runout 右删失项的对数正态极大似然。Johnson/MRR 和仅断裂点回归只用于审计。全 runout 只说明在中止寿命前未失效，不能拟合出有限寿命斜率或确认疲劳极限。

Miner 损伤假定线性累积且忽略载荷次序。概率可靠性对每个模拟零件使用共享的 S-N 纵向散差，并可叠加整体载荷倍率 COV。

报告中的“存活率 Ps=90% 对应寿命”表示 90% 零件预计能达到的寿命；`Pf [ppm]` 表示目标寿命前失效的概率，不使用含糊的 `N90` 命名。

## 工程边界

本结果用于方案比较、试验数据解释和风险筛选，不能替代正式标准签发、企业放行规范、试验认证或有限元热点应力确认。
