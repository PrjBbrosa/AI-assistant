# 轴向受力螺纹连接：新手校核指南

这是一条从“我有一颗螺栓”走到“我知道哪个环节不满足”的完整操作路线。第一次使用时，先用测试案例跑通界面，再替换成自己的数据；不要一上来同时修改所有参数。

## 先确认：这个模块适不适用

适用的结构是：螺栓直接拧入带内螺纹的对手件，中间没有需要保持夹紧的法兰、垫片或多层被夹件，服役载荷是沿螺栓轴线方向的拉力。

以下情况不适用：

- 两个法兰或多层板靠螺栓预紧力夹在一起，需要判断残余夹紧力或密封能力；这类连接应使用 VDI 2230 螺栓连接模块。
- 存在横向力、防滑要求、偏心弯矩、服役扭矩或多颗螺栓共同分担载荷。
- 需要完整载荷谱、连接体柔度、接触分离或标准签发级结论。

本模块把外部轴向拉力全部计入螺栓，不计算被夹件载荷分配，也不输出残余夹紧力。

## 最快上手：先跑“测试案例 1”

1. 点击右上角“测试案例 1”。案例会载入一组 M8、8.8 级、扭矩法装配且包含螺纹脱扣输入的数据。
2. 不修改任何字段，点击“执行校核”。
3. 页面会跳到结果步骤。先看顶部总体结论，再看四个分项徽章：装配强度、服役强度、疲劳和螺纹脱扣。
4. 展开或阅读警告与建议，确认自己能找到装配扭矩、服役应力、疲劳许用幅和脱扣安全系数等结果。
5. 回到输入步骤，每次只改一类数据后重新计算。例如先只增大 `FA_max`，观察服役强度和疲劳如何变化。

测试案例用于学习操作与结果结构，不是你的设计推荐值。

## 换成自己的数据前要准备什么

至少准备以下资料：

- 螺纹规格：公称直径 `d`、螺距 `p`、强度等级或实际屈服强度 `Rp0.2`。`As`、`d2`、`d3` 会由 `d/p` 自动派生，不需要照图纸重复填写。
- 装配条件：可保证的最小预紧力、装配散差系数 `alpha_A`、螺纹和支承面摩擦系数、支承内外径、拧紧方式。
- 服役载荷：一个循环中的最小轴向拉力 `FA_min` 和最大轴向拉力 `FA_max`。静载时两者可取相同值。
- 螺纹啮合：有效啮合长度 `m_eff`、内螺纹对手件许用剪应力 `tau_BM`。如果不知道这两项，脱扣不能得到结论。
- 疲劳信息：预计循环次数和螺纹成形方式；服役安全系数则按项目要求输入。

摩擦系数、预紧力、材料强度和有效啮合长度应来自图纸、供应商资料、装配规范或经过确认的工程输入，不要直接把测试案例数值当成通用默认值。

## 按左侧顺序填写

### 1. 适用范围与建模假设

先做工况筛选。只要实际结构出现被夹件、横向力、弯矩或多螺栓分载，就先停止，不要靠调安全系数弥补模型不适用。

### 2. 螺纹与材料参数

先填 `d` 和 `p`，确认自动派生的螺纹截面已更新；再选择强度等级。选择“自定义”时，`Rp0.2` 才由用户负责。弹性模量用于变形相关的基础参数，不代表材料强度。

### 3. 预紧与装配参数

最小预紧力与 `alpha_A` 一起决定最大装配预紧力。摩擦系数和支承直径影响所需拧紧扭矩以及装配扭转应力。拧紧方式还会影响服役阶段保留多少装配扭转的简化处理。

### 4. 轴向工作载荷

保证 `FA_max >= FA_min >= 0`。循环载荷的差值影响应力幅，整体水平影响平均应力和最大服役应力。不要把横向载荷或弯矩换算成一个轴向力后直接塞入，除非已有独立且可追溯的等效方法。

### 5. 螺纹脱扣

建议把这一步当作必要输入，尤其是螺栓拧入铝合金或铸铁壳体时。填写 `m_eff` 后，`tau_BM` 必须有效；`tau_BS` 留空时工具按螺栓屈服强度派生。脱扣结果会指出控制侧是螺栓外螺纹还是对手件内螺纹。

### 6. 交变轴向疲劳与输出选项

循环次数和表面处理影响简化疲劳许用幅；`rolled` 与 `cut` 不是外观选项，而是不同的螺纹成形条件。报告模式只改变输出详略，不改变计算结论。

最后点击“执行校核”。任何输入修改都会让旧结果失效，需要重新计算后才能导出。

## 结果怎么判读

总体结论有三种：

- **校核通过**：四个分项都已执行且通过。仍需阅读警告、模型范围和输入来源，不能只看绿色标题。
- **校核不通过**：至少一个已执行分项失败。先找失败徽章，再看建议，不要只盯总体标题。
- **校核不完整**：没有已失败项，但存在未校核项。最常见原因是 `m_eff` 留空，螺纹脱扣显示“未校核”。“不完整”不是通过。

四个分项建议按以下顺序读：

1. 装配 von Mises：判断最大装配预紧力与拧紧扭转共同作用时是否超限。
2. 服役最大 von Mises：判断预紧力叠加 `FA_max` 后的最大强度。
3. 交变轴向疲劳：比较实际应力幅与平均应力修正后的许用幅。
4. 螺纹脱扣：比较螺纹剪切承载与最大螺栓力，并查看哪一侧控制。

## 失败后怎么调整

- 装配强度失败：先核对预紧力和摩擦输入；可降低预紧力、改善装配散差、改用低残余扭转工艺、增大规格或提高强度等级。降低预紧力前要确认连接功能仍满足。
- 服役强度失败：可降低外载、增大规格或提高强度等级；同时确认 `FA_max` 没有重复乘入工况放大。
- 疲劳失败：优先降低 `FA_max - FA_min`、降低平均载荷、增大规格或改善螺纹成形和表面质量。单纯提高静强度等级不一定按同样比例改善疲劳。
- 脱扣失败：若对手件侧控制，可增加有效啮合长度或提高对手件材料强度；若螺栓侧控制，可增加啮合长度、增大规格或复核螺栓材料。
- 结论不完整：补齐 `m_eff` 和对手件剪切强度后重新计算，不要导出“不完整”结果当作放行依据。

每次只改变一到两个有物理意义的参数，重新计算并记录变化原因，避免为了得到绿色结果而任意调数。

## 模型边界与使用责任

本工具是面向工程预校核的简化模型，不覆盖横向防滑、偏心弯曲、多螺栓载荷分配、被夹件柔度、完整疲劳载荷谱和连接面分离。非扭矩装配方式及疲劳能力也包含简化假设。结果不能替代原始标准核对、图纸评审、供应商数据、试验或有限元分析。

本文只说明当前软件实现与操作顺序，不引用未经核对的标准条号，也不把测试案例视为标准推荐。
