# 赫兹接触校核新手指南

## 先判断这个模块是否适合你

适合：两个弹性体受纯法向力时，快速估算外接触的最大接触应力。可选择圆柱-圆柱或圆柱-平面的“线接触”，也可选择球-球或球-平面的“点接触”。本工具用你填写的许用最大接触应力 `[p0]` 判断通过或不通过。

不适合：内滚道或凸凹内接触、负曲率、两个平面直接接触、明显塑性变形、需要边缘修正的有限长接触，以及要同时评估摩擦、切向力、冲击时程、润滑、粗糙度、磨损或接触疲劳寿命的场景。这里也不是完整轴承或齿轮寿命模块。

## 最快上手：先跑测试案例 1

1. 点击页面右侧“测试案例 1”。页面会载入线接触示例：`R1=30 mm`、`R2=0`（平面）、`L=20 mm`、法向载荷 `12000 N`，许用值 `[p0]=1500 MPa`。
2. 点击“执行校核”。
3. 打开“校核结果与消息”。正常应看到最大接触应力约 `855.68 MPa`、安全系数约 `1.753`，总体为通过。
4. 先不要改很多值。只把法向载荷或 `R1` 改一次并重新计算，观察 `p0` 和安全系数的变化。

测试案例只是演示流程和字段格式，不能直接当成你的正式工况。

## 换成实际工况前要准备什么

- 接触类型：确认是线接触还是点接触，不能只按零件名称猜。
- 几何：两个接触体在接触方向上的曲率半径 `R1/R2`；平面填 `0`。线接触还要准备有效接触长度 `L`。
- 材料：两接触体的弹性模量 `E1/E2` 和泊松比 `nu1/nu2`。材料下拉带出的是建议值；选择“自定义”后再填写自己的数据。
- 载荷：接触区的峰值法向载荷 `F`。切向力和冲击附加载荷不会由本工具自动折算。
- 许用值：最终可用的 `[p0]`。它要由材料、热处理、寿命、润滑和工况等依据确定；材料下拉不会自动生成权威许用值。

常用单位为：长度 `mm`、力 `N`、弹性模量和接触应力 `MPa`。

## 推荐的校核顺序

1. 在“校核目标”填写 `[p0]`。采样点数和曲线载荷上限倍率只控制结果曲线，不会提高核心公式精度。
2. 在“接触模型与几何”选择线接触或点接触，再填半径；两个半径不能同时为 `0`。线接触填写 `L`，点接触时 `L` 不参与计算。
3. 在“材料参数”确认两组 `E` 和 `nu`。不要把材料下拉理解成许用接触应力数据库。
4. 在“法向载荷”填写峰值法向力。
5. 点击“执行校核”，再进入“校核结果与消息”看结论和提示。

任何输入变化都会使旧结果和导出状态失效，修改后要重新执行校核。

## 结果怎么读

- `p0`：接触区中心的最大接触应力，是本页唯一硬判据的计算值。
- `[p0]`：你输入的许用最大接触应力。`p0 <= [p0]` 才通过。
- 安全系数：`[p0] / p0`。小于 `1` 表示不通过；低于 `1.2` 时程序还会给出裕量偏低的提醒。
- `b`：线接触的接触半宽；`a`：点接触的接触半径。它们用于理解接触斑大小，不是独立的通过判据。
- `E'` 和 `R'`：程序由两组材料参数和两侧曲率自动得到的等效量。
- 压力-载荷曲线：帮助观察载荷变化趋势。它不会替代寿命、磨损或动态分析。

通过只说明当前赫兹 `p0` 判据通过，不代表所有接触失效模式都已覆盖。

## 不通过时先调整什么

1. 先复核 `[p0]`、单位、接触类型、半径和载荷是否来自可靠工况，不能为了得到通过而随意抬高 `[p0]`。
2. 在结构允许时增大有效曲率半径，使接触更平缓。
3. 线接触可增加有效接触长度，但要另外关注有限长度的端部效应。
4. 降低峰值法向载荷，或在上游结构中分散载荷。
5. 依据材料和热处理资料选择更合适的接触副，再用有依据的 `E/nu/[p0]` 重新校核。

一次只改一个主要参数并重新计算，便于确认真正起作用的方向。

## 模型边界

本页使用线性弹性赫兹解析模型，当前只接受非负曲率并按外接触处理；负曲率和内接触不会被当作已支持模型。计算没有加入弹塑性、有限长度边缘修正、摩擦剪应力、粗糙峰、润滑膜、温升、磨损和接触疲劳寿命。短线接触（`L < 5 mm`）会提示核查边缘效应，但程序不会自动完成三维修正。

因此，本页适合方案比选和快速预校核；需要正式签发或模型边界外的工况时，应使用适用标准、试验或更完整的接触分析复核。
