# 花键连接校核指南（新手版）

这份指南按“先跑通案例，再替换自己的数据”的顺序使用。当前模块是 **DIN 5480 / DIN 6892 风格的简化预校核**，用于方案初筛，不等同于完整标准校核或设计签发。

本文依据当前代码、模块帮助和公开工程资料整理，**未查证原始标准正文（Cannot verify against original DIN standard）**，不引用或代述标准的具体条款。

## 1. 先判断是否适用

**适用：**

- 渐开线花键的齿面平均承压预校核。
- 已知扭矩、模数、齿数、啮合长度和许用齿面压力，想快速判断承载余量。
- “联合”模式下，同时复核花键轴光滑圆柱段的过盈防滑和材料应力。

**不适用：**

- 平键、矩形花键、锥面或其他非渐开线连接。
- 需要完整校核齿根弯曲、剪切、内花键胀裂、磨损寿命、公差与齿侧间隙链的场合。
- 需要出具 DIN 5480 / DIN 6892 完整合规结论或正式签发报告的场合。

本页只有两种计算范围：**仅花键**与**联合**。联合模式是在花键预校核之外增加光滑段过盈复核，不代表已覆盖全部轴毂连接失效模式。

## 2. 用测试案例 1 最快上手

1. 点击顶部 **测试案例 1**，载入一组公开尺寸模式的仅花键输入。
2. 点击 **执行校核**。
3. 在“计算结果”查看场景 A：齿面压力 `p`、许用压力 `p_zul`、安全系数 `S` 和预校核结论。
4. 看到场景 B 显示“已跳过”是正常的，因为案例 1 使用“仅花键”模式。
5. 回到输入页，每次只改一个值（例如扭矩或啮合长度），重新执行，观察安全系数如何变化。

案例 1 只用于熟悉流程。换成真实项目时，必须核对图纸几何、材料许用值、工况系数和目标安全系数。

## 3. 输入前准备什么

- **计算范围**：确认只校核花键，还是还存在需要复核的光滑过盈段。
- **花键几何**：优先准备标准规格或图纸上的 `m`、`z`、参考直径、轴齿顶/齿根直径、内花键齿顶直径和啮合长度 `L`。
- **载荷**：名义扭矩、轴向力（联合模式使用）以及能反映冲击/过载的工况系数 `K_A`。
- **承载依据**：材料或企业规范给出的许用齿面压力 `p_zul`，以及齿面载荷分布系数 `k_alpha`。
- **判定门槛**：齿面最小安全系数；联合模式还需防滑和材料应力的最小安全系数。
- **联合模式附加数据**：光滑段轴径、轴内径、轮毂外径、有效配合长度、过盈上下限、材料弹性参数/屈服强度、摩擦系数和粗糙度。

没有可靠图纸尺寸时可以用“近似”模式初筛，但正式判断应切回公开/图纸尺寸。不要为了得到 PASS 而随意提高许用压力或降低系数。

## 4. 推荐计算顺序

1. **校核目标**：选择“仅花键”或“联合”，设置安全系数门槛和 `K_A`。
2. **花键几何**：选标准规格或录入图纸尺寸，再确认 `L`、`k_alpha`、`p_zul`。
3. **光滑段过盈**：仅联合模式填写；仅花键模式下本章不参与计算。
4. **载荷工况**：填写名义扭矩和轴向力。
5. 点击 **执行校核**，先看总体预校核结论，再看各场景明细、警告和建议。

计算中 `K_A` 放大外部设计载荷，`k_alpha` 反映花键齿间载荷分布不均，两者含义不同，不能互相替代。

## 5. 怎样读结果

- **预校核通过**：当前已覆盖判据满足目标门槛；不代表完整 DIN 6892 校核通过。
- **预校核不通过**：至少一个已执行判据未达到目标，应先定位失败项，不要只看总体徽章。
- **齿面压力 `p`**：越小越有利；应与同一材料、寿命和工况依据下的 `p_zul` 比较。
- **齿面安全系数 `S = p_zul / p`**：必须达到设定的 `S_flank,min`。扭矩容量比与它是同一判据的另一种表达，不是第二个独立安全裕量。
- **联合模式场景 B**：防滑与材料应力是两个独立判据，两者都要看。过盈曲线帮助理解装配范围，但不能替代工艺验证。
- **警告/建议**：包含简化模型和未覆盖项；即使结果通过也应阅读。

## 6. 不通过时优先怎么调

- 齿面压力过高：在结构允许时增加啮合长度、增大有效尺寸或齿数、降低设计扭矩，或改善载荷分布以降低有依据的 `k_alpha`。
- `K_A` 导致余量不足：先复核真实峰值载荷和驱动/负载冲击，不能无依据地把 `K_A` 调小。
- 联合模式防滑不足：可在材料与装配允许范围内增加有效配合长度、合理调整过盈或改善有证据支持的摩擦条件。
- 联合模式应力不通过：不要继续盲目增加过盈；应复核轴/轮毂壁厚、材料强度和配合方案。
- 近似模式不通过：先用真实图纸尺寸复核；近似几何采用保守方向，可能高估齿面压力。

每次调整一个主要变量并重新计算，同时记录调整依据，避免“调到通过”却失去可追溯性。

## 7. 模型边界与下一步

本模块只给 **simplified precheck（简化预校核）**。花键部分未覆盖齿根弯曲、剪切、轮毂胀裂、磨损寿命、完整公差/变位/齿侧间隙链，也没有逐项实现 DIN 6892 的完整系数体系。联合模式的光滑段只补充圆柱过盈的防滑和材料应力复核。

对高冲击、反复换向、关键安全件、疲劳寿命敏感或需要标准合规签发的设计，应使用完整标准计算、经验证的专用软件或第三方工程校核，并结合图纸公差、材料批次和装配工艺验证。
