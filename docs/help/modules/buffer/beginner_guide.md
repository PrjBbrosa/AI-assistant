# 缓冲块吸能仿真新手指南

## 先判断这个模块是否适合你

适合：已经有缓冲块加载/卸载 `F-x` 测试曲线，希望估算一次水平冲击能否在可用行程内吸收动能，并检查行程、曲线能量容量和峰值力。

不适合：没有可靠测试曲线、连续往复或多次冲击、明显应变率或温度效应、垂直跌落中重力做功不可忽略，以及需要真实阻尼系数、接触后结构振动或触底峰值的场景。时域曲线是能量守恒反推结果，不是真实时域动力学仿真。

## 最快上手：先跑测试案例 1

1. 点击页面右侧“测试案例 1”。它会导入自带的 CSV 加载/卸载曲线，并启用“执行仿真”。
2. 保持默认工况：质量 `12 kg`、初始速度 `1.5 m/s`、可用行程 `30 mm`、允许峰值力 `9000 N`。
3. 点击“执行仿真”。
4. 在“吸能结果”中，正常应看到初始动能 `13.50 J`、最大压缩约 `14.40 mm`、峰值力约 `2371 N`，行程、峰值力和曲线能量容量三项均通过。
5. 再看“响应时程”和“参数对比”，理解它们是近似响应和敏感度结果，不是新增的独立试验数据。

测试案例只用于跑通流程。换成正式工况时，必须导入与你的缓冲块、温度、加载方向和测试条件相匹配的曲线。

## 输入准备

- 加载和卸载 `F-x` 曲线：支持 CSV 或 XLSX，既可用宽表，也可用 `branch + 位移 + 力` 的长表。位移单位为 `mm`，力单位为 `N`。
- 冲击质量 `m`：撞击物或运动部件的等效质量，单位 `kg`。
- 初始速度 `v0`：接触缓冲块前的速度，单位 `m/s`。
- 可用行程：机构允许的最大压缩量，单位 `mm`。
- 允许峰值力：结构、导轨和安装件可承受的上限，单位 `N`。
- 曲线力倍率、行程倍率：对试验曲线做敏感度缩放；它们不能把未经验证的缩放曲线变成正式材料数据。
- 卸载噪声容差：只用于容忍卸载曲线局部略高于加载曲线的测量噪声，不应靠放大它掩盖不合理曲线。

曲线起点不是 `(0,0)` 时程序会补点并给出警告；卸载曲线明显高于加载曲线时会拒绝计算，因为这违反当前耗散假设。

## 推荐的仿真顺序

1. 点击“导入曲线文件”，或先用“测试案例 1”。导入成功后检查点数、最大行程、最大加载力和 warning 数量。
2. 进入“曲线检查与能量”，确认加载/卸载支路、方向和单位没有填反。
3. 在“单次冲击工况”填写质量、速度、可用行程和允许峰值力；首次正式计算时先保持倍率为 `1.00`。
4. 点击“执行仿真”，先看“吸能结果”的总体结论与三项徽章。
5. 再看“响应时程”和“参数对比”，最后到“结果说明 / 导出”复核并留档。

更改输入或曲线后，旧结果与导出会立即失效，必须重新执行仿真。

## 结果怎么读

- 初始动能：`0.5 * m * v0^2`，速度变化会按平方影响需求能量。
- 最大压缩：加载曲线累计能量达到初始动能时的位移。
- 峰值力：最大压缩位置在线性插值后的加载力；只有未触底时才可判定。
- 行程：最大压缩是否不超过输入的可用行程。
- 曲线能量容量：在“可用行程”和“测试曲线最大行程”的较小值内，曲线面积是否足以吸收初始动能。
- 回弹速度：由卸载曲线在本次最大压缩范围内的能量估算。
- 响应时程：由能量守恒反推的 `x(t) / v(t) / a(t) / F(t)`，只能看近似趋势。

如果动能超过可用容量，结果会标记“触底”：行程和能量容量不通过，触底后的真实峰值力为不可判定，不应把曲线末端力当作安全峰值。

## 不通过时先调整什么

1. 先核对质量、速度、单位和曲线是否属于同一实际缓冲块。速度填错会显著放大动能。
2. 能量容量或行程不通过时，可降低质量/速度、增加实际可用行程，或选用加载曲线面积更大的缓冲块。
3. 峰值力不通过时，优先选择更软且有足够行程和能量容量的方案，或在系统层面降低速度/分散载荷。
4. 用“参数对比”观察力倍率和行程倍率的敏感度；正式设计仍应回到可验证的实测曲线。
5. 回弹过大时关注卸载曲线面积和滞回耗能，并结合真实回弹试验复核。

降低峰值力、缩短压缩量和提高吸能容量之间可能互相制约，调整后要重新检查全部三项判据。

## 模型边界

本页按准静态加载/卸载 `F-x` 曲线做单次冲击能量法。模型假设水平冲击或重力做功可忽略；垂直跌落时需要把重力做功计入能量，本版本不会自动处理。它不从曲线唯一识别真实粘性阻尼，不含应变率、温度、材料老化、多次冲击、结构柔性和触底后的动力学。

浅压缩工况仍截取同一条测试卸载支路估算回弹，真实卸载路径可能不同。时域响应数值失败时，程序只保留能量法结果并给出警告。因此，本页适合试验曲线驱动的方案比选与预估，不替代真实冲击试验或完整动力学仿真。
