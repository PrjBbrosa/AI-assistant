# 过盈配合：新手校核指南

这份指南用于第一次完成“轴—轮毂圆柱过盈配合”的输入、计算和判读。建议先跑测试案例认识结果，再逐步替换为自己的几何、公差、材料和载荷。

## 先确认：这个模块适不适用

适用于圆柱轴与厚壁轮毂的实心轴或空心轴过盈连接，用于预校核以下问题：最小过盈端能否传递扭矩和轴向力，径向力与弯矩是否可能造成张口缝，最大过盈端的轴和轮毂应力是否可接受，以及压装或热装工艺量级。

以下情况不要直接用本结果放行：

- 锥面、花键、键连接、非圆柱接触或明显局部接触。
- 轮毂有开口、键槽、复杂台阶、极薄壁或几何突变，导致接触压力明显不均匀。
- 材料进入塑性、温度显著改变材料性能、摩擦随压力或速度变化。
- 需要精确评估端部效应、局部峰值、旋转弯曲疲劳或标准签发级结论。

本模块采用线弹性、均匀接触压力和常摩擦系数的工程简化。空心轴会修正柔度，并在轴侧应力判定中考虑内孔壁与配合面较危险的一侧。

## 最快上手：先跑“测试案例 1”

1. 点击右上角“测试案例 1”。页面会载入一组轴—轮毂案例；部分版本启动后也会自动载入这组示例，但仍建议主动点击一次，确认数据来源。
2. 点击“执行校核”。
3. 先看结果页总体结论，再逐项看扭矩、轴向、联合作用、张口缝、需求过盈覆盖、轴应力和轮毂应力。
4. 查看接触压力的 `p_min / p_mean / p_max`、所需过盈、压入力以及警告。
5. 如果案例开启了 Fretting 评估，再看风险等级和建议；它是增强结果，不改变基础总体通过/不通过。
6. 回到输入页，每次只改一个变量。例如只增大扭矩，观察防滑支线；只增大最大过盈，观察能力增加与应力升高的权衡。

测试案例用于演示按钮、数据流和结果结构，不等于你的零件应采用相同配合或摩擦系数。

## 换成自己的数据前要准备什么

- 几何：配合直径 `d`、轴内径 `d_i`（实心轴填 0）、轮毂外径 `D`、有效配合长度 `L`。
- 过盈窗口：最小与最大直径过盈量，或者能够换算它们的轴孔偏差。只知道一个名义过盈值不足以同时判断防滑和应力两端风险。
- 材料：轴和轮毂的弹性模量 `E`、泊松比 `nu`、屈服强度 `Re`。材料下拉项只自动填 `E/nu` 建议值，屈服强度仍由用户确认并输入。
- 载荷：最大传递扭矩、轴向力、径向力、弯矩，以及统一的工况系数 `KA`。
- 表面与装配：服役周向/轴向摩擦系数、装配摩擦系数、两侧 `Rz`、粗糙度压平系数，以及压装或热装需要的工艺参数。
- 判据：项目要求的防滑最小安全系数和材料最小安全系数。

优先使用图纸公差链、材料保证值、加工检测和已确认的装配状态。摩擦系数对传递能力很敏感，不能仅凭“钢对钢”四个字确定。

## 按左侧顺序填写

### 1. 校核目标

先确定防滑与应力安全系数门槛，再填 `KA`。`KA` 会先放大名义载荷，安全系数则是在设计载荷之上要求的裕量；不要在载荷输入中又预先重复放大。曲线采样点数只影响图线平滑度。

### 2. 几何与过盈

检查 `0 <= d_i < d < D`，并填真实有效接触长度。过盈来源可选：

- “直接输入过盈量”：已有完整公差计算结果时使用。
- “优选配合”：从软件内置的有限预设换算，必须确认预设适合你的名义尺寸和图纸体系。
- “偏差换算”：已有轴、孔上下偏差时使用，工具据此生成最小/最大过盈。

防滑主要看最小过盈端，应力主要看最大过盈端，所以不能只优化其中一个数值。

### 3. 材料参数

`E` 和 `nu` 决定轴与轮毂的径向柔度，`Re` 决定应力安全系数。选择材料牌号后仍要手工核对两侧屈服强度，尤其要区分材料状态、热处理和保证值。

### 4. 载荷与附加载荷

扭矩和轴向力用于防滑能力与联合作用；径向力和弯矩用于附加压力与张口缝判断。没有某类载荷时填 0，不要留给工具猜测。确认载荷是名义值，统一由 `KA` 放大。

### 5. 摩擦与粗糙度

周向摩擦 `mu_T`、轴向摩擦 `mu_Ax` 和装配摩擦 `mu_Assy` 用途不同。粗糙峰压平会从输入过盈中扣除一部分，形成有效过盈；若压平后有效最大过盈不大于 0，计算会停止。批量生产还要控制加工纹理、毛刺、清洁和润滑一致性。

### 6. 装配流程

`manual_only` 只给通用压入力量级；`shrink_fit` 估算轮毂所需加热温度并检查温度限制；`force_fit` 使用独立的压入/压出摩擦估算设备载荷。装配模式改变工艺输出，不改变基础防滑与应力判据。

### 7. Fretting 风险评估

开启后根据载荷谱、严酷度、表面状态和重要度给出规则化风险等级与建议。该结果是简化增强项；关闭或不适用时，不代表已经证明“没有微动腐蚀风险”。

最后点击“执行校核”。输入一旦变化，旧结果和导出状态会失效，需要重新计算。

## 结果怎么判读

应用的通用结论词汇包含“通过 / 不通过 / 不完整”，但当前过盈核心计算在必填输入齐全后只产生以下两种总体结论：

- **校核通过**：七个核心分项全部通过。仍要阅读警告、装配建议、Fretting 增强结果和模型边界。
- **校核不通过**：至少一个核心分项失败。按失败徽章定位到防滑、张口缝、过盈覆盖或应力支线。
- **校核不完整 / 未校核**：这是应用的通用第三态。当前过盈模块缺失或非法必填输入时会停止计算，不会把旧结果包装成“不完整”；Fretting 关闭也不会使基础总体结论变成“不完整”。因此看见输入错误时，应补齐数据并重新执行，而不是沿用上一次结果。

建议按“两端风险”读结果：

1. 最小过盈端：看扭矩、轴向、联合作用和张口缝。这里回答“最松的合格零件是否还传得动”。
2. 需求过盈覆盖：比较当前最大可用过盈与载荷所需过盈，确认公差窗口覆盖需求。
3. 最大过盈端：看轴和轮毂 von Mises 安全系数。这里回答“最紧的合格零件是否会应力过高”。
4. 工艺输出：压入力或热装温度用于设备和工艺预估，不应与服役通过/不通过混为一谈。

## 失败后怎么调整

- 扭矩、轴向或联合作用失败：可增加最小过盈、增加配合长度、在有证据时提高服役摩擦系数，或降低载荷。扭矩与轴向力同时存在时优先看联合作用，不能只让两个单项刚好通过。
- 张口缝失败：增加最小接触压力储备，常见方向是提高最小过盈、增加有效长度或降低径向力/弯矩；复杂弯曲工况建议升级分析方法。
- 需求过盈覆盖失败：提高可用最大过盈，或通过增加长度、合理摩擦和降低载荷来减小所需过盈，同时继续检查最大端应力。
- 轴应力失败：可减小最大过盈、提高轴材料强度；空心轴还可复核内径，因为内孔壁可能控制。
- 轮毂应力失败：可减小最大过盈、增大轮毂外径或提高轮毂材料强度。
- 压入力过高或热装温度超限：调整装配方式、装配摩擦、间隙或材料热膨胀输入，并核对设备能力与材料热处理限制。这不是通过修改服役摩擦来“修好”的问题。
- Fretting 风险高：增加防滑裕量、减小循环载荷、改善表面保护或通过试验/更高保真模型复核。

过盈增大会提高传递能力，也会提高材料应力和装配难度。每次调整后都要同时复查最小端能力、最大端应力和装配工艺。

## 模型边界与使用责任

本模块是圆柱过盈连接的工程预校核，不模拟端部接触峰值、局部塑性、复杂轮毂开口、温度依赖材料、摩擦非线性和完整疲劳过程。径向力、弯矩、重复载荷与 Fretting 均包含简化或规则化处理。关键部件应结合原始标准、图纸公差分析、材料与摩擦试验、装配试验以及必要的有限元分析。

本文只说明当前软件实现与操作顺序，不引用未经核对的标准条号，也不把内置配合或测试案例视为标准推荐。
